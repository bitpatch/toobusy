# Contributing

toobusy is a small project, and help is always welcome.

- Have an idea of what it lacks or what it should do differently? Open an issue and tell.
- Found a bug? Open an issue. Know how to fix it? Open a pull request.
- Have Linux or Windows at hand? Only macOS is tried by hand. Build toobusy there, try it and write what came of it.

Development happens on `develop`: branch from it and open pull requests against it. `main` holds released code only.
